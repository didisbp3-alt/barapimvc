Autenticação de API é o mecanismo que permite verificar se quem está fazendo uma requisição para sua API 
realmente tem permissão para acessá-la (ou seja, "quem é você e você pode fazer isso?").
Em um contexto comum de desenvolvimento C# (ASP.NET Core), onde você tem um frontend 
web (Blazor, React, Angular, Razor Pages, etc.) conversando com uma API que acessa um 
banco de dados (SQL Server, PostgreSQL, etc.), a autenticação é essencial para proteger 
os dados e as operações.
